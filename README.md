# 山行补给 · 产品展示版

基于山行补给现有产品制作的独立静态展示站。选择三个头像之一即可体验，无需注册或密码。

## 展示内容

- 欢迎页介绍产品、演示范围与正式版邀请体验方式。
- 沿用现有产品的输入页、配餐结果页和个人主页。
- 固定参数：60 kg、175 cm、25 岁、男、偶尔徒步、基础负重 8 kg、无特殊饮食限制、携带方便。
- 西湖爱心线约 19.98 km，两日行程；第一天 22:00 至第二天 08:00 睡眠。
- 人为设定的杭州初秋天气场景，非实时天气。
- 预设六顿正餐、两次途中加餐、饮水库存及备用物资；支持查看全部携带清单、保存示例和下载离线清单。

所有输入下拉框只有一个选项且不可修改。配餐结果是固定展示，不是根据个人身体参数计算的营养建议。正式版目前通过邀请体验，需联系产品提供者获取账号和当次访问链接。

## 隐私与运行方式

此目录仅包含公开展示文件，不含服务器、真实账号、数据库、密码或 API 密钥。不会调用 Dify 或其他模型服务，页面通过内容安全策略禁止连接 API。头像和示例记录仅保存在当前浏览器，可以在个人主页清除。

食品标签数据和通用食品估值沿用现有产品；通用食物参考 USDA FoodData Central。页面保留参考数据、不确定性和固定示例标识。食物库存不等同个体生理需求。

## GitHub Pages 发布

1. 将本目录中的 `index.html`、`assets/`、`.nojekyll` 和此 README 上传到仓库根目录。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch。
3. 选择实际上传文件的分支（通常 main）及 `/ (root)`，点击 Save。
4. 等待 GitHub 显示发布网址。

站点使用相对资源路径和 `#/input`、`#/plan`、`#/profile` 路由，支持 GitHub Pages 项目子路径和页面刷新。没有需要运行的后端，电脑关机后仍可由 GitHub Pages 提供访问。

展示流程已精简：输入页的“生成方案”为可重复跳转按钮；邀请体验说明仅在输入页展示；餐食热量、全部携带食品热量及总碳水分开说明。行程休息与无中途补给合并展示，个人主页注明迪卡侬标签资料与通用食品来源。
